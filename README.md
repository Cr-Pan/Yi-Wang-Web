# Yi Wang Academic Website

Personal academic website for Yi Wang, an Economics Ph.D. student at The Ohio State University.

## Update content

Most public text is centralized in `content/site-content.md`. The portrait is stored at
`public/images/yi-wang-portrait.png`, and the downloadable CV is `public/Yi-Wang-CV.pdf`.

## Local development

```bash
npm install
npm run dev
```

The configured local route is `http://localhost:3000/Yi-Wang-Web/`.

## Verify the static site

```bash
npm run build
```

Pushes to `main` are published through the GitHub Pages workflow.
